TokenRouter — One gateway for multiple AI providers, with secure routing and concurrency-safe token accounting.

The problem

Applications need one gateway for different AI provider protocols, with usage accounting that stays consistent when requests overlap or fail.

What I built

Built an OpenAI-compatible LLM gateway that converts between provider protocols, routes by priority and weight with failure-aware retries, and reserves and settles token quotas concurrency-safely.

An engineering decision

User and API-token quota holds are paired in one database transaction. Settlement and refunds are idempotent, and durable reservation records keep failed operations available for reconciliation.

Evidence in the code

The test suites cover atomic settlement, repeated settlement and refunds, rollback on failure, and concurrent reservations that cannot overspend.

  • Architecture overview
  • Quota reservation implementation
  • Atomicity and idempotency tests
  • Concurrent quota tests

MobileID — A Django/Vue identity platform with barcode workflows and control over sessions on other devices.

The problem

A mobile identity application needs barcode and profile workflows alongside control over authenticated sessions on other devices.

What I built

Built a Django/Vue identity platform for PDF417 barcode generation, profile management, and device-aware sessions on PostgreSQL and DynamoDB.

An engineering decision

Cookie-based JWT authentication combines refresh-token blacklisting with access-session revocation checks on subsequent API requests. Cookie-authenticated writes also require CSRF validation.

Evidence in the code

Tests cover device listing, revoking one or all other devices, rejection of revoked access tokens, and CSRF enforcement. CI configures a 70% backend coverage floor alongside security checks and Playwright suites.

  • API authentication
  • Device revocation implementation
  • Device management tests
  • Cookie authentication security tests
  • CI quality gates
